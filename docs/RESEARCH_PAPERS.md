## Research Papers & Dataset Sources

1. **Krishna River + Deep Learning Forecasting**  
   Kaur & Chavan (2025) — *Comparative analysis of deep learning and machine learning models for one-day-ahead streamflow forecasting in the Krishna River basin*  
   https://doi.org/10.1016/j.ejrh.2025.102549

2. **Cauvery River + Streamflow Forecasting**  
   Naganna et al. (2023) — *Daily scale streamflow forecasting in multiple stream orders of Cauvery River, India: Application of advanced ensemble and deep learning models*  
   https://doi.org/10.1016/j.jhydrol.2023.130320

3. **Rainfall Dataset — IMD 0.25° × 0.25° Gridded Rainfall**  
   Pai et al. (2014) — *Development of a new high spatial resolution (0.25° × 0.25°) long period (1901–2010) daily gridded rainfall data set over India and its comparison with existing data sets over the region*  
   https://doi.org/10.54302/mausam.v65i1.851

4. **Temperature Dataset — IMD Gridded Temperature**  
   Srivastava, Rajeevan & Kshirsagar (2009) — *Development of a high resolution daily gridded temperature data set (1969–2005) for the Indian region*  
   https://doi.org/10.1002/asl.232

5. **Streamflow Dataset — CWC / India-WRIS**  
   Goteti (2023) — *Geospatial dataset for hydrologic analyses in India (GHI): a quality-controlled dataset on river gauges, catchment boundaries and hydrometeorological time series*  
   https://doi.org/10.5194/essd-15-4389-2023

6. **ONI / ENSO Dataset — NOAA**  
   NOAA Climate Prediction Center — *Oceanic Niño Index (ONI)*  
   https://www.cpc.ncep.noaa.gov/products/analysis_monitoring/enso/oni/

7. **ENSO Reference**  
   Kousky & Higgins (2007) — *An Alert Classification System for Monitoring and Assessing the ENSO Cycle*  
   https://doi.org/10.1175/WAF987.1
